PRISM — 사내 Workspace + ERP를 혼자 처음부터 설계·구축

빈 저장소에서 시작해 업무 흐름 분석, 데이터 모델, 화면, API, 데이터 수집 자동화, 배포·운영까지 1인 풀스택으로 완성했습니다. 흩어진 쇼핑몰·결제·이카운트 자료를 한곳에 모아 정산·대사·경영 보고까지 이어지게 만들었습니다.

완성한 기능

  • Workspace 문서 허브 · 주간업무 · 프로젝트
  • 데이터 수집 Cafe24 · Shopify · 이카운트 · 결제사 자동 수집 (API · Playwright)
  • 데이터 반영 엑셀 Import → Staging 검증·승인 → 기준정보
  • 매출 원장 승인된 매출을 채널·팀·거래처·품목별 조회
  • 회계·보고 월 정산표 · 재경 대사 · 월간 실적 · 품목 포트폴리오 · 경영 보고 · 매출 분석

다음 단계: 구매 · 재고 · 생산 · HR 모듈

설계 포인트

  • WEB · ERP · Auth 분리, 공통 세션으로 한 번 로그인
  • 서비스마다 UI와 API를 이미지 하나로 배포, 태그 하나로 롤백
  • OpenAPI 명세에서 TypeScript 클라이언트 자동 생성
  • PostgreSQL 하나로 데이터 · 작업 큐 · 세션 처리 (Redis 없음)
  • Caddy 호스트 분기, 수집은 systemd 타이머, pg_dump 백업
